# QGIS連動 xROAD構造物検索ツール

国交省の「全国道路施設点検データベース（xROAD）」APIを活用し、入力された橋梁やトンネル等の施設名から位置情報・諸元データ等を一括取得し、**QGISに直接読み込めるGeoJSON形式**として書き出すツールです。

## 主な機能

1. **ドラッグ＆ドロップで対象施設を一括検索**
   - 確認したい施設名が記載されたテキストファイルやCSVを画面にドラッグ＆ドロップするだけで、xROAD APIから対象の施設データを一括検索します。

2. **AI（Gemini）による強力なテキスト自動抽出**
   - 施設点検の調書ファイル（**PDF**）や、人間が書いたメモ書きのような自然文などが含まれたファイルであっても、`gemini-2.5-flash` APIが文脈を解釈し、必要な「施設名」だけを自動で抽出します。
   - 例: `158-上半原-003` のような一見名前には見えない管理番号や、ゴミテキストが混ざった資料からでも正確に抜き出せます。

3. **柔軟な検索・同名施設の自動判別**
   - API側での「全角・半角」の表記ゆれ（例：`大橋１２３` vs `大橋123`）を自動的に吸収して取りこぼしを防ぎます。
   - 検索候補が複数存在する場合でも、画面上で「管理者」「路線名」「寸法（橋長・幅員など）」「市区町村」がプレビューされるため、どれが正しい施設かを簡単に判別できます。
   - ファイル検索でも都道府県と市区町村（部分一致）を指定し、同名施設の候補を対象自治体まで絞り込めます。

4. **QGIS連携用ファイル（Zip）の一発出力**
   - 検索・確定した施設一覧は、APIから取得したすべての属性データ（点検履歴や諸元など）を保持したまま `GeoJSON` フォーマットに変換されます。
   - 自動で色分け・アイコン表示が行われる `QML` スタイルファイルと共にZip化されるため、ダウンロードしてQGISにそのままドロップするだけで可視化が完了します。

## 対象施設
UI上部のタブから切り替えることで、以下のxROADデータセットに対応しています：
- 橋梁 (Bridges)
- トンネル (Tunnels)
- シェッド (Sheds)
- 大型カルバート (Culverts)
- 横断歩道橋 (Pedestrian Decks)
- 門型標識等 (Signs)

## 必要環境

- **Python 3.x**
- xROAD API へのアクセスが可能なネットワーク環境
- 以下のPythonライブラリが必要です:
  ```bash
  python -m pip install -r requirements.txt
  ```

## 使い方

1. **APIキーの設定**
   - PDF等からのAI抽出機能を使用するためには、Gemini APIキーが必要です。
   - `appsettings.sample.json` を `appsettings.json` にコピーし、`gemini_api_key` にAPIキーを設定することもできます（`appsettings.json` はGit管理対象外です）。
   - コマンドプロンプト等で環境変数 `GEMINI_API_KEY` を設定してください。
   - 例（Windows）: `setx GEMINI_API_KEY "あなたのAPIキー"`

2. **サーバーの起動**
   - ツールフォルダ内にある `start.cmd` をダブルクリックして実行するか、ターミナルから以下を実行します。
   ```bash
   python server.py
   ```
   - サーバーが立ち上がると、自動的にブラウザが開き `http://localhost:8080` の検索画面が表示されます。

3. **データの検索と出力**
   - 検索したい施設の種類をタブで選択します（例：「橋梁」）。
   - PDFやCSV、テキストファイルを画面中央の枠にドラッグ＆ドロップします。
   - AIが自動で施設名をテキストから抽出し、xROAD APIで検索を行います。
   - 画面下部に検索候補が複数出た場合は、寸法や路線名などを手動で確認して[確定]ボタンを押します。
   - すべての施設が確定し「出力リスト」に移動したら、画面最下部の**「QGIS用Zipをダウンロード」**をクリックします。

4. **QGISへのインポート**
   - ダウンロードした `search_results.zip` を解凍します。
   - 中に入っている `search_results.geojson`（データ本体）と `search_results.qml`（デザイン設定）を、QGISのレイヤパネルへドラッグ＆ドロップすると、即座にマップ上にピンが立ち、属性テーブルから全データが確認できます。

## 共有フォルダでの複数人利用（管理者向け）

橋梁・トンネル等のデータ検索と「地図管理」への保存・閲覧・社内用メモ／位置の編集を、他の人ともLAN経由で共有したい場合の手順です。ツール自体のコード改修はこのPC（管理者PC）だけで行い、実行だけを共有する構成を想定しています。

### 1. 社内共有フォルダを用意する

年度/業務名別のGeoJSONを置く場所を決めます（例: `\\ファイルサーバー\共有\xROAD_map_data`）。ここは**データ保存専用フォルダ**で、コード本体を置く必要はありません。書き込み権限が必要な利用者からアクセスできることを確認してください。

### 2. appsettings.json を設定する

プロジェクトフォルダで `appsettings.sample.json` を `appsettings.json` としてコピーし、以下を編集します（`appsettings.json` はGit管理対象外です）。

```json
{
  "gemini_api_key": "（PDF自動抽出を使う場合のみ設定。Excel/CSVのみなら空でも可）",
  "data_dir": "\\\\ファイルサーバー\\共有\\xROAD_map_data",
  "bind_host": "0.0.0.0",
  "port": 8080,
  "auth_user": "（共有用のユーザー名を決めて設定。例: rebircle）",
  "auth": "（共有用の合言葉パスワードを決めて設定）"
}
```

- `data_dir` を空のままにすると、従来通りプロジェクト内 `data/` に保存され、共有されません。必ず共有フォルダのパスを指定してください。
- `bind_host` を空のままにすると `localhost` 限定（このPCからしかアクセスできない）になります。他PCから使えるようにするには `0.0.0.0` を指定してください。
- `port` は共有URLを固定するために番号を指定します（未指定だと起動のたびに空きポートが変わり、他の人に伝えたURLが変わってしまいます）。
- `auth` は必ず設定してください。未設定のまま `bind_host` を公開すると、サーバーは起動しません。`auth_user` を空のままにすると、ユーザー名は何を入力しても通ります（パスワードのみで照合）。
- Basic認証は通信を暗号化しません。`http://` のLAN公開では認証情報と検索・地図データが盗聴され得るため、インターネットへは公開しないでください。利用範囲を社内ネットワーク/ファイアウォールで限定し、社外アクセスが必要ならHTTPSのリバースプロキシまたはVPN/Tailscaleで保護してください。
- 保存済み業務を同名で更新・削除する際は、他の利用者が変更していないことを版数で確認します。競合時は最新データを確認してから明示的に上書きしてください。

### 3. サーバーを起動する

`start.cmd` を実行するか `python server.py` を実行します。起動ログに表示されるURL（例: `http://192.168.x.x:8080`）と、`appsettings.json` に設定したユーザー名・パスワードを利用者に伝えてください。このPCの電源が入っていて、このプロセスが起動している間だけ他の人も使えます。

### 4. コード一式の予備コピーを共有フォルダに置く（復旧用、任意）

管理者PCが使えなくなったときに別PCから起動し直せるよう、共有フォルダに実行用のコピーを置いておくと安心です。

- コピーする: `server.py` / `index.html` / `static/`（`leaflet/`・`map.js` を含む） / `projects_store.py` / `style_sample.qml` / `requirements.txt` / `start.cmd`
- コピーしない: `appsettings.json`（Gemini APIキーや共有パスワードが入っているため、不特定多数がアクセスできる場所には置かない）、`data/`（`data_dir`を共有フォルダに向けていれば不要）
- `appsettings.json` は、実際にそのPCで起動する担当者が別途手元で用意してください。
- 併せて[使い方ガイド.html](使い方ガイド.html)も共有フォルダに置くと、利用者がブラウザで開くだけで使い方を確認できます。

### 5. 利用者への案内

- アクセスURL、共有ユーザー名・パスワード、[使い方ガイド.html](使い方ガイド.html)を伝えれば、利用者側は何もインストールせずにブラウザだけで使い始められます。
